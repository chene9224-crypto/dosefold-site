# GLP1 Journal — website and legal pages

Public product website, Terms of Use and Privacy Policy for the GLP1 Journal iPhone app.

- Home: https://glp1-journal-site.pages.dev/
- Terms: https://glp1-journal-site.pages.dev/terms/
- Privacy: https://glp1-journal-site.pages.dev/privacy/

The site is static, uses no advertising cookies or tracking pixels, and has no framework or build step. Open `index.html` directly or serve this directory with any static file server.
