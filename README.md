# Dosefold — website and legal pages

Public product website, Terms of Use and Privacy Policy for the Dosefold iPhone app.

- App Store name: **Dosefold — GLP-1 Tracker**
- In-app display name: **Dosefold**
- Category phrase: GLP-1 tracker

## Pages

- Home: https://dosefold-site.pages.dev/
- Terms: https://dosefold-site.pages.dev/terms/
- Privacy: https://dosefold-site.pages.dev/privacy/

Deployed with Cloudflare Pages project `dosefold-site`; production branch `main`.

The site is static, uses no advertising cookies or tracking pixels, and has no framework or build step. Open `index.html` directly or serve this directory with any static file server.

## Structure

```text
index.html          Product website
styles.css          Shared visual system
assets/             App logo and favicon
terms/index.html    Terms of Use
privacy/index.html  Privacy Policy
```

## Subscription copy

The Terms include a subscription section (auto-renewal, billing through Apple, cancellation, restore, refunds, trials, price shown before purchase, deleting the app does not cancel) and the Privacy Policy documents RevenueCat as subscription infrastructure. Both are written without stating a price, trial length, or plan features, because those are set in App Store Connect.
